Server Commands

Nützliche Befehle

Die wichtigsten Spielerbefehle auf einen Blick – so findest du dich auf NoName SMP sofort zurecht.

🌍

Teleportation

/spawn

Teleportiert dich zum Server-Spawn.

/home set <name>

Erstellt ein Home an deinem aktuellen Standort.

/home tp <name>

Teleportiert dich zu einem deiner Homes.

/home delete <name>

Löscht eines deiner Homes.

/homes

Listet alle deine Homes auf.

/tpa <spieler>

Sendet eine Teleport-Anfrage an einen Spieler.

/tpaccept

Akzeptiert eine Teleport-Anfrage.

/tpdeny

Lehnt eine Teleport-Anfrage ab.

/back

Kehrt zu deinem vorherigen Standort zurück.

/warp tp <name>

Teleportiert dich zu einem Warp.

💬

Chat & Kommunikation

/msg <spieler> <nachricht>

Sendet eine private Nachricht.

/reply <nachricht>

Antwortet auf die letzte private Nachricht.

/r <nachricht>

Kurzform von /reply.

/ignore <spieler>

Ignoriert die privaten Nachrichten eines Spielers.

/voicechat

Öffnet das Simple Voice Chat Menü/Einstellungen.

💰

Wirtschaft

/pay <spieler> <betrag>

Sendet Geld an einen anderen Spieler.

/balance

Zeigt deinen aktuellen Kontostand.

/bal

Kurzform von /balance.

/servershop

Öffnet den Server-Shop zum Kaufen/Verkaufen.

/orders claim

Beansprucht eine offene Bestellung.

/orders request

Erstellt eine neue Bestellung.

🏠

Land Claims

/spawn

Hole dir hier die Claim-Schaufel.

Rechtsklicke mit der Claim-Schaufel zwei gegenüberliegende Ecken, um den Bereich dazwischen zu claimen.

/claim abandon

Löscht deinen aktuellen Claim.

/claim trust <spieler>

Gibt einem Spieler Zugriff auf deinen Claim.

/claim untrust <spieler>

Entfernt den Zugriff eines Spielers.

/claims

Listet deine Claims auf.

Hinweis: Du kannst maximal 5 Homes gleichzeitig haben. Einige Befehle sind möglicherweise nicht verfügbar oder funktionieren je nach Server-Setup und installierten Plugins etwas anders.
